# 抖屏助手（dyshuaping）

一个**仅限本人自用、临时调试**的 Android 无障碍工具：在用户手动开启后，通过 AccessibilityService 操作抖音直播间评论框，按随机节奏循环执行「定位输入框 → 输入文字 → 点发送 → 等界面回到直播间」的流程。可随时暂停、继续或停止。

- Debug APK，包名 `com.mqx.dyshuaping`，版本 `1.1.0`
- 默认目标应用：`com.ss.android.ugc.aweme`（抖音）
- 无 Hook、无 root、无 Xposed、无 Shizuku、无改包名、无模拟器伪装
- 只读取和操作设置中目标包名的窗口，其他 App 一律不触碰

> ⚠️ 免责声明见文末。频繁刷屏可能违反平台规则，导致限流或封号，请自行评估并承担风险。

### v1.1 更新

- v1.1.0：新增悬浮窗「补发一次」单发按钮，用于测试账号是否被禁言；不追加随机后缀，结束后不恢复主循环，长按可改发送内容，结果在悬浮窗显示 5 秒并写入耗时日志。

## 1. 能做什么

- 多条评论内容（一行一条），随机抽取或顺序循环发送
- 每条评论末尾自动追加 1~3 个防重复后缀（符号 / 数字 / 抖音表情代码，可多选）
- 最近 20 条已用的完整后缀尽量不重复（`ArrayDeque` 记录）
- 随机发送间隔、每轮 0~800ms 抖动、点击坐标 ±3px、按压 30~80ms
- 悬浮窗：开始 / 暂停 / 停止 / 试一轮 / 补发一次 / 抓节点 / 坐标校准 / 隐藏
- 悬浮窗「补发一次」：仅在已暂停或已停止状态执行一次完整单发，用于**测试自己是否被禁言**；不追加随机后缀，不恢复主循环；结果醒目显示 5 秒；长按按钮可直接修改补发内容
- 通知栏常驻前台服务：暂停 / 继续 / 停止
- 全屏半透明双十字准星校准，节点定位失败时坐标兜底
- 单步调试日志（最近 200 条），一键复制 / 分享
- 当前窗口节点树抓取，写入 `/sdcard/Download/dyshuaping_nodes.txt` 并弹出分享
- 切出抖音自动暂停，切回抖音自动继续；连续失败 3 次自动暂停

## 2. 构建

环境要求：JDK 17、Android SDK（compileSdk 34 / build-tools 34.0.0）。

```bash
cd /home/mqx/projects/dyshuaping
./gradlew assembleDebug
# 或
./build.sh
```

构建产物：

```text
app/build/outputs/apk/debug/app-debug.apk
dist/app-debug.apk   # build.sh 会复制一份
```

项目已配置国内 Maven 镜像（阿里云）和腾讯 Gradle 分发镜像。若本机没有 `JAVA_HOME` / SDK 环境，`build.sh` 会尝试使用本机已验证的 `~/toolchains/dyshuaping/jdk` 和 `~/android-sdk`。

## 3. 安装

```bash
# 方式一：adb
adb install -r app/build/outputs/apk/debug/app-debug.apk
# 或
./install.sh

# 方式二：把 APK 传到手机，点击安装
```

首次安装需允许“安装未知应用”。

## 4. 开启三项权限

打开 App，按“运行权限”卡片的顺序操作：

1. **悬浮窗权限**：点击“去授权”，在系统设置允许“显示在其他应用上层”。
2. **通知权限**：Android 13+ 会弹系统通知授权；如果之前拒绝过，点击卡片按钮进入系统通知设置手动打开。
3. **无障碍服务**：点击“去开启”，在系统无障碍列表中找到「抖屏助手 · 自动评论」并开启。

## 5. Android 13+ 与 ColorOS 的“受限设置”

在 ColorOS / realme UI / OxygenOS 等系统上，侧载 APK 后无障碍开关可能是灰的：

**应用信息 → 右上角 ⋮ → 允许受限设置**，然后再打开无障碍服务。

小米 / vivo 等系统建议同时允许“后台弹出界面”、自启动、后台运行，避免悬浮窗或前台服务被回收。

## 6. 坐标校准

1. 先在系统中打开抖音并进入一个直播间，确认评论框显示“说点什么…”或类似占位符。
2. 回到抖屏助手，点击「开始校准」，或从悬浮面板点「校准坐标」。
3. 会出现半透明校准层：
   - **蓝色十字**拖到评论输入框中心；
   - **红色十字**拖到红色「发送」按钮中心。
4. 校准层只拦截两个十字和顶部控制卡片的触摸，其余区域可以正常操作抖音。
5. 点击「保存校准」。坐标按屏幕宽高归一化存储，运行时乘以真实屏幕尺寸，用于不同分辨率。

校准坐标只在无障碍节点定位失败时兜底使用；正常情况下优先读取「说点什么 / 和主播聊两句 / 写评论 / 发个评论」文本或可编辑 `EditText`。

## 7. 使用步骤

1. 依次开启悬浮窗、通知、无障碍三项权限。
2. 先进入抖音直播间，确认评论输入框可见。
3. 回到抖屏助手点击「开始」，或者打开悬浮球点「开始」。
4. 再切回抖音；如果不是从抖音内启动，工具会先显示“等待切回抖音”，检测到抖音恢复前台后自动开始。
5. 悬浮面板可观察状态、已发送条数、下一轮倒计时；也可按「暂停」「停止」「试一轮」「补发一次」「抓节点」。
6. 调试建议先暂停，再点「试一轮」，看“日志”页里每一步结果。
7. **判断是否被禁言**：先暂停（或停止）主循环，再点悬浮窗「补发一次」。它只发一轮、不追加任何后缀、结束后仍保持暂停/停止，不会自动继续；默认内容是 `怎么回事？发不了了`。长按「补发一次」按钮可弹出输入框修改，设置页的「补发内容」也可改，保存后立即生效。
8. 「补发一次」完成后，悬浮窗会醒目显示 5 秒：`已发出`、`未发出：找不到输入框`、`未发出：文字没进去（输入框为空或内容不匹配）` 或 `未发出：发送按钮不可点（大概率被禁言）`；日志页同时追加一条包含原文、各阶段耗时和失败原因的记录。

## 8. 参数说明

| 参数 | 默认 | 说明 |
|---|---:|---|
| 消息列表 | 3 条示例 | 一行一条，空行忽略；修改后下一轮生效 |
| 发送模式 | 随机抽取 | 随机抽取 / 顺序循环 |
| 防重复后缀 | 开启 | 每条评论末尾追加后缀 |
| 后缀类型 | 符号+数字+表情代码 | 可多选 |
| 后缀数量 | 2 个 | 1~3 个 |
| 后缀去重 | 最近 20 条 | 记录已发送的完整后缀并尽量避开 |
| 最小间隔 | 3 秒 | 1~60 秒 |
| 最大间隔 | 8 秒 | 1~60 秒，且不小于最小值 |
| 每轮抖动 | 0~800ms | 自动加在每轮等待后 |
| 点击抖动 | ±3px | 避免永远落在完全相同的像素 |
| 按压时长 | 30~80ms | 每次点击随机 |
| 目标包名 | `com.ss.android.ugc.aweme` | 只操作该包名窗口 |
| 校准坐标 | 未设置 | 输入框 / 发送按钮归一化坐标 |
| 补发内容 | `怎么回事？发不了了` | 「补发一次」的单发文本；不追加后缀，单行，修改后立即生效 |

符号池：`~ ～ … !! ？？ 。。 ☀ 🌙 ✨ 🍀 👍`

抖音表情代码池：`[比心] [爱心] [鼓掌] [玫瑰] [666] [一起加油] [坏笑] [礼物] [黄脸祈祷] [害羞] [微笑]`

示例效果：`主播唱得真好听~[比心][666]123`

> 单一类型且后缀数量为 1 时，组合总数可能不足 20 条，无法绝对满足“最近 20 条不重复”；此时会选择可用的组合并继续轮转。

## 9. 常见问题

**发送键点不动**
- 先校准发送按钮。
- 看日志里是否显示「发送按钮置灰」；置灰说明文字没有真正进入输入框。
- 部分机型需要开启输入法悬浮权限或切换系统输入法；工具会优先使用 `ACTION_SET_TEXT`，失败后退回剪贴板 + `ACTION_PASTE`。

**文字没有进去**
- 确认点击的是直播间评论输入框，而不是其他搜索框。
- 看日志里 `ACTION_SET_TEXT` 是否返回 true、校验文本是否包含目标内容。
- 用「抓节点」检查输入框是否暴露 `editable=true`、节点 text 是否可读。

**被限流 / 发送后看不到**
- 暂停并降低频率，减少重复内容。
- 平台可能有发送频率限制、风控或折叠展示；本工具不包含绕过风控的处理。

**耗电 / 被系统杀后台**
- 保持通知常驻，允许自启动和后台运行。
- ColorOS / MIUI 请在电池设置里把本 App 设为“不限制”。
- 无障碍服务可能被系统在长时间无操作后中断；重新开启即可。

**悬浮窗看不到**
- 检查“显示在其他应用上层”权限。
- 打开 App 点「显示 / 恢复悬浮窗」。
- 若从悬浮面板点过「隐藏」，也可以从通知进入 App 恢复。

**为什么要前台服务**
- 常驻通知提供暂停 / 继续 / 停止入口，并降低进程被系统回收的概率。通知属于低优先级，不响铃。

## 10. 抓节点、日志与分享

- 「抓节点」只抓当前目标包名窗口的 `rootInActiveWindow`，记录 `className / text / contentDescription / viewIdResourceName / boundsInScreen / clickable / editable` 等字段。
- Android 10+ 通过 MediaStore 写入 `Download/dyshuaping_nodes.txt`；Android 9 及以下需要存储权限，未授权时会退回到应用私有目录并弹出分享。
- 运行日志最多保留 200 条，存放在内存中，可在「运行日志」页一键复制或分享。
